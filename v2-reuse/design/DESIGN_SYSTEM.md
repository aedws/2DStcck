# 화면 디자인 인계 기준

## 시각 방향

- 기본 배경은 짙은 흑회색, 카드 표면은 한 단계 밝은 회색으로 구분합니다.
- 금융 정보는 장식보다 숫자의 위계가 먼저 보이게 구성합니다.
- 상승은 붉은색, 하락은 파란색인 기존 한국 시장 표기 체계를 유지합니다.
- 기본 강조색은 파란색이며, 우선주·보호 신탁·캐릭터 애착 요소에는 금색 계열을 제한적으로 사용합니다.
- 모서리는 카드 16~24px, 입력과 버튼 10~14px 반경을 기본으로 합니다.

## 정보 위계

1. 현재 가격·순자산·주문 상태
2. 변동률·호가·시장 압력
3. 종목/캐릭터 설명과 보조 지표
4. 튜토리얼·안내·운영 문구

거래 성공 여부와 저장·정산 상태는 색상만으로 표시하지 말고 텍스트 상태를 함께 노출합니다.

## V2 핵심 화면

- 공통 시장 홈: 시장 국면, 지수, 실시간 압력, 거래대금, 주요 종목
- 종목 상세: 차트, 호가, 체결, 주문, 공매도/파생상품 진입점
- 포트폴리오: 현금, 평가자산, 실현/미실현 손익, 증거금, 정산 대기
- 캐릭터/기업: 캐릭터 관계, 우선주, 기업 지배구조, 이벤트와 서사
- 유저 ETF/기관: NAV, 구성, 괴리율, 설정·환매, 기관 책임과 영향력

## 포함된 컴포넌트

- `StockLogo.tsx`: 로고 실패 시 티커 이니셜로 대체
- `Sparkline.tsx`: 최소 시세 추이 표시
- `FlashValue.tsx`: 값 변경 강조 애니메이션

세 컴포넌트는 표시 책임만 갖습니다. 주문, 잔액, 저장소에는 접근하지 않습니다.
